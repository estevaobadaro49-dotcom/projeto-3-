# Regras de negócio

1. Uma consulta precisa estar associada a um paciente e a um profissional existentes.
2. Uma consulta deve possuir modalidade válida: Presencial ou Online.
3. O status da consulta deve ser Agendada, Concluída, Cancelada ou Pendente.
4. Valores financeiros não podem ser negativos.
5. O registro profissional e o e-mail do paciente são únicos.
6. Um pagamento pertence a uma única consulta.
7. Dados pessoais utilizados no projeto devem ser fictícios.
